# 波动状态与价格位置方向挖掘协议（事前声明，2026-09-30）

方向：**波动状态与价格位置（VOLPOS）族**。延续动量/反转的时间序列思路，但从「涨跌方向」转向
「价格在自身近期轨迹中的位置 + 波动状态」——与跳空族（隔夜信息）正交。

- 主假设：T+3 反转强度受**波动状态**与**价格位置**调节——高波动/极值位置后的反转更强
  （彩票型、注意力冲击）；低波动压缩后的方向延续或平静反转（机制不同）；
- 镜像假设：位置本身是动量（趋势中的新高延续）；
- 证伪友好：若位置/波动层均无独立于既有反转族的增量，以负结果收场（同 mom/gap 条款）。

机制登记（延续四方向经验：换手乘法器有效、振幅乘法器不跨族、裸动量证伪、T+3 反转存活）：
1. **价格位置**：close 在 N 日高/低区间的位置；距 N 日高/低点距离（20/60 日）
2. **区间结构**：N 日高低区间宽度、当日振幅 (high-low)/close
3. **波动水平与压缩**：收益波动率 vol20、短/长波动比 vol5/vol20（squeeze→expansion）
4. **波动条件化反转/动量**：−Δ₅ × cs_rank(vol20)（高波反转）；−Δ₅ × (1−cs_rank(vol20))（低波反转）
5. **位置 × 活跃度**：位置 × cs_rank(turnover)、反转 × 换手 × 位置（三件套移植）
6. **压缩后反转**：−Δ₅ × cs_rank(vol_ratio)（squeeze 后的反转/延续）

## 预算与停机

- 轮次：≤4 轮；每轮 10–20 候选；本轮预算 ≤80
- 早停：连续 2 轮最优 valid |RankIR| 提升 <5% 且无新结构方向；或方向证伪成立
- 噪声锚点（N=80）：√(2·ln 80) ≈ 2.96；有效样本 ≈244 → |RankIR| 绝对优势门槛 ≈ **0.19**

## 选择纪律（沿 gap_protocol 全部条款）

1. 只看 train（存在性）+ valid（排序）；test/lockbox 不作选择
2. 统计不可区分（valid |RankIR| 差 <0.02）取最简
3. 参数看平台不看峰值；组合只正交等权
4. 留存 ≤3；三票制（|valid RankIR|>0.19 + 经济机制 + 最简）至少两票
5. 留存因子须记录与 PV_ANTI_TRIPLE / GAP_DIFF4_TURN 的 train/valid 截面相关
6. 多头换手 >60% 须三档成本排序不变才可主推
7. 至少 1 轮跨轮复跑逐位对比
8. 位置类因子天然暴露于涨跌停/停牌极值，报告中声明

# 真实摩擦与统计不确定性报告

对留存因子补齐毛/净收益、换手、回撤、置信区间，并加入费用、印花税、滑点、涨跌停/停牌与容量约束。统计显著性使用 HAC(Newey–West) 与平稳区块 bootstrap。

## 口径声明

- 股票池：沪深300 成分（000300.SSE），共 819 只标的
- label：`ts_delay(close,-3)/ts_delay(close,-1)-1`（T+1→T+3 收盘到收盘）
- 执行假设：T+1 收盘成交；建仓日剔除停牌与**涨停**（涨停不可买入）
- 分位：每日截面十分位；多头组 = Q10（等权）
- **融券约束**：A 股个股普遍不可做空 → **多头为准**；多空组合仅作对照，不视为可实施
- 重叠收益处理：HAC 滞后 3 期；bootstrap 平稳区块 B=2000、块长 10
- **年化/回撤口径**：收益序列按非重叠 3 日块抽取（每 3 个交易日取一），年化因子 244/3；避免重叠收益累加/连乘造成的重复计入
- IC 统计量仍用全部交易日（IC 是相关系数序列，不受重叠收益口径影响）

## 局限（如实声明）

- 涨跌停以「日收益 ≥ 阈值×0.98」近似；**ST 股 5% 限制无法识别**，会被误判为可交易
- 跌停时无法卖出未额外剔除（持有至 T+3 的假设偏乐观）
- 未建模冲击成本的非线性、融券费用、分红除权、指数成分调整生效日
- 容量估算仅用 ADV 代理与 10% 参与率，未考虑多因子叠加与交易拥挤
- 多空组合在 A 股个股层面不可实施，仅作信号强度参照

## 2. 股票池与成分

| 项 | 约定 |
|---|---|
| 池 | 沪深300（`000300.SSE`）成分股 |
| 成分处理 | 由 `AlphaLab.load_component_filters` 展开为**存续区间**，`prepare_data(filters=...)` 按日生效 |
| 幸存者偏差 | 已通过存续区间过滤规避（成分变更按日生效，非用最终成份回填） |

## 3. 复权与价格口径（**重要局限**）

| 项 | 约定 |
|---|---|
| 归一化 | `lab.load_bar_df` 将每股价格**除以其首日 close**（跨标的可比） |
| 日收益 | `close / prev_close − 1` —— 除以常数不改变收益率，**口径不受归一化影响** |
| 复权 | **上游 lab 数据未声明是否前复权/后复权**，本仓库无法核实。若原始数据为未复权价，除权日会出现虚假跳空。此项为已知未核实约束（见局限） |
| volume/turnover | 原始量纲，未归一化 |

## 4. 信号与成交时点

| 项 | 约定 |
|---|---|
| 因子计算时点 | 第 T 日**收盘后**（因子表达式只使用截至 T 的字段） |
| 执行假设 | **T+1 收盘**成交（本报告基准口径） |
| 退出时点 | T+3 收盘 |
| label 公式 | `ts_delay(close,-3) / ts_delay(close,-1) - 1` |
| 重叠性 | 逐日样本共享 2 日持有期 → **重叠收益**，显著性须用 HAC / 区块 bootstrap |

> 说明：T+1 收盘成交相对 T+1 开盘成交偏乐观；更保守的开盘执行口径未在本轮实现，列为局限。

## 5. 分段与停止规则

| 段 | 区间 | 用途 |
|---|---|---|
| train | 2008-01-01 ~ 2016-12-31 | 信号存在性 |
| valid | 2017-01-01 ~ 2018-12-31 | 排序选择（唯一决策依据之一） |
| test | 2019-01-01 ~ 2020-08-31 | 挖掘期隐藏，终局观察一次 |
| lockbox | 2020-09-01 ~ 数据末尾 | 留存决策冻结后仅作展示 |

- 预算：≤4 轮，每轮 10–20 候选，总数 ≤80
- 早停：连续 2 轮最优 valid |RankIR| 提升 <5% 且无新结构方向
- 噪声锚点：N=80 时 √(2·ln 80) ≈ 2.96，有效样本 ≈244 → |RankIR| 绝对优势门槛 ≈ **0.19**
- 留存：≤3 个因子，三票制（绝对优势 + 经济机制 + 最简形式）至少两票

各方向的具体条款见 `../volpos_protocol.md`、`../gap_protocol.md`、`../mom_protocol.md`。
